We have developed this program with sustainability in mind. 
We have used Lighthouse to inspect our programs sustainability. It got a performance rating of 98, 
an accessibility rating of 86, a best practices rating of 100, and an SEO rating of 82.

Our HTML is a bit messy, which is one of the reasons our accessibility rating is 86. 
Under performance, we have a network dependency tree that chains requests. This is something we will be keeping an eye on for our next project.

In this project we have used a Test Last approach. We felt that it would be better for us to get a sense of the methods needed, before testing.

For our first deployed TypeScript and C# project, we are very proud of the work we have done.
